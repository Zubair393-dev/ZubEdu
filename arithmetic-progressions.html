Chapter 5 • Arithmetic Progressions

Important Question 1

Find the 10th term of the AP: 2, 5, 8, 11, ...

Solution:

a = 2, d = 5 − 2 = 3, n = 10

aₙ = a + (n − 1)d
a₁₀ = 2 + 9(3)
= 2 + 27

Answer: 29

Important Question 2

Find the 20th term of the AP: 7, 10, 13, 16, ...

Solution:

a = 7, d = 3, n = 20

a₂₀ = 7 + (20 − 1)3
= 7 + 57

Answer: 64

Important Question 3

Find the sum of the first 20 terms of the AP: 3, 7, 11, 15, ...

Solution:

a = 3, d = 4, n = 20

Sₙ = n/2 [2a + (n − 1)d]

S₂₀ = 20/2 [6 + 19(4)]
= 10 [6 + 76]
= 10 × 82

Answer: 820

Important Question 4

Which term of the AP 5, 9, 13, 17, ... is 81?

Solution:

a = 5, d = 4, aₙ = 81

aₙ = a + (n − 1)d
81 = 5 + (n − 1)4
76 = 4(n − 1)
19 = n − 1

Answer: n = 20

Important Question 5

Find the sum of the first 15 natural numbers.

Solution:

The AP is 1, 2, 3, ..., 15.
a = 1, d = 1, n = 15

Sₙ = n/2 [2a + (n − 1)d]
S₁₅ = 15/2 [2 + 14]
= 15/2 × 16

Answer: 120
